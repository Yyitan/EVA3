# EVA3 — A Troika-Framework Reproduction of EVA (Decoupling Primitive with Experts, ICLR 2026)

> A complete implementation of **EVA** (Mixture-of-Experts Framework for Semantic Variant
> Alignment), reproduced on the MIT-licensed code framework of
> [Troika](https://github.com/bighuang624/Troika) (CVPR 2024, arXiv:2303.15230).
> This repository contains **fully runnable code**: Troika's original files are kept
> as-is, with newly added MoE Adapter and semantic variant alignment modules.

## 1. Method Summary

EVA makes two core changes on top of a frozen CLIP ViT-L/14 (method credit belongs to
the original EVA paper; this repository is a reproduction/extension of it on the
Troika code framework):

1. **Domain-Expert Adaption (MoE Adapter)**: a MoE Adapter is injected **in parallel to
   the FFN of every layer** of both the image and text encoders — 1 shared expert +
   8 routed experts, TopK=2, each expert LoRA-structured (r=64, with B matrices
   zero-initialized so training starts smoothly from frozen CLIP); the Router is a
   single linear layer scoring token-to-expert affinity (covering all 24 image layers
   + 12 text layers);
2. **Semantic Variant Alignment (SVA)**:
   - text-to-image: a partner-max loss (with learnable temperatures τs/τo, implemented
     via scatter-max);
   - image-to-text: the outputs of each expert in the last layer are treated as image
     variant CLS embeddings; after inter/intra affinity, the variant chosen by argmax
     is used for alignment;
3. **Training objective**: `L = Lc + λ1·(Ls + Lo) + λ2·(Lvs + Lvo)`; the composition
   loss is a CE over `softmax(fc·tc/τ)` (τ is the native CLIP temperature); three sets
   of soft prompts (Pc/Ps/Po, "a photo of x x" style, Troika-style);
4. **Inference scoring**: `score = pc + β·(ps + po)`.

Key hyperparameters (paper Sec. 4.1 / appendix): Ne=8, K=2, r=64, α=0.5, λ1=0.5, λ2=0.1,
β=0.5, lr=1e-4, 20 epochs, Adam; weight decay: MIT 1e-4 / UT 5e-4 / CGQA 1e-4.
Trainable parameters: ~39.2M.

## 3. Reproduction Steps

### 3.1 Environment

The same environment as Troika works (archived runs used torch 1.13.1+cu117):

```bash
conda create -n troika python=3.8
pip install -r code/requirements.txt
```

You also need the OpenAI CLIP `ViT-L-14.pt` weights, passed in via `--clip_arch`.

### 3.2 Datasets

MIT-States, UT-Zappos, and C-GQA, downloaded and prepared with the scripts in this repository:

```bash
cd code/download_data
bash download_data.sh
# Open-world evaluation additionally requires data/feasibility_<dataset>.pt,
# generated by download_data/feasibility.py (loaded automatically by the configs)
```

### 3.3 Training (Closed-World)

```bash
cd code
CUDA_VISIBLE_DEVICES=0 python -u train.py \
    --yml_path config/eva/ut-zappos.yml \
    --dataset_path data/ut-zappos \
    --clip_arch /path/to/ViT-L-14.pt \
    --save_path output/ut --num_workers 10 --seed 0
# For MIT-States / C-GQA, just swap in the corresponding config and data paths
```

Each epoch evaluates automatically on val, and `val_best.pt` is saved according to
`val_metric: AUC`.

### 3.4 Evaluation

```bash
# Closed-World
python -u test.py --yml_path config/eva/ut-zappos.yml \
    --dataset_path data/ut-zappos --clip_arch /path/to/ViT-L-14.pt \
    --save_path output/ut --load_model output/ut/val_best.pt

# Open-World (uses *-ow.yml, loads feasibility_*.pt automatically)
python -u test.py --yml_path config/eva/ut-zappos-ow.yml \
    --dataset_path data/ut-zappos --clip_arch /path/to/ViT-L-14.pt \
    --save_path output/ut --load_model output/ut/val_best.pt
```

Note: the MoE has a larger GPU memory footprint than Troika. Measured on an A100-40G,
the batch size must be reduced to UT 32 (with gradient accumulation 2), MIT 32, and
CGQA 24. For more implementation details and choices the paper leaves unspecified, see
[`code/README.md`](code/README.md).

## 4. Reproduction Results

The following are the **reproduced values of this repository's implementation** as
recorded in [`code/REPRODUCTION_REPORT.md`](code/REPRODUCTION_REPORT.md) (paper-reported
values in parentheses for comparison; the reproduced values fall below the paper values,
and an analysis of the sources of the gap can be found in that report):

| Setting | Dataset | Reproduced AUC | Paper AUC |
|---|---|---|---|
| Closed-World | UT-Zappos | 37.3 | 50.2 |
| Closed-World | MIT-States | 20.8 | 24.0 |
| Open-World | UT-Zappos | 24.9 | 40.2 |
| Open-World | MIT-States | 6.5 | 9.4 |

For horizontal reference (UT-Zappos closed-world AUC): CSP 33.0, a CLIP + soft-prompt
baseline without MoE/SVA 29.7, Troika 41.7, this reproduction 37.3 (paper EVA 50.2).
